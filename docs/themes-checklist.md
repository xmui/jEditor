# Themes checklist

Every part of jEditor, in every theme: written by `node design/themes/audit.js`, which opens each screen at 1280×800 and 1024×640 and checks each part for words or buttons off screen or cut off, things under the title bar, buttons with neither words nor an icon, words cut off without "…", words still in jEditor's own font, and theme files that aren't there. Run it again after a change to a theme.

✓ nothing found · ⚠ n problems (listed below) · — not on screen in that theme

Checked 2026-10-23.
